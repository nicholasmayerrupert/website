# Audio asset sources

These files are edited derivatives of recordings published under Creative
Commons Zero (CC0). Attribution is not required, but the sources are retained
here so the asset history stays auditable.

- `sand-flow.wav`: “SAND POUR.wav” by nicoproson —
  https://freesound.org/people/nicoproson/sounds/627070/
- `water-flow.wav`: “Water Stream.wav” by metaepitome —
  https://freesound.org/people/metaepitome/sounds/181320/
- `tnt-firework.mp3`: “Firework Explosion 2” by deleted_user_3544904 —
  https://freesound.org/people/deleted_user_3544904/sounds/212682/
- `tnt-slam.mp3`: “fireworks” by loganzsound —
  https://freesound.org/people/loganzsound/sounds/774236/
- `tnt-deep.mp3`: “Deep Explosion” by Kodack —
  https://freesound.org/people/Kodack/sounds/258195/

Edits: trimmed, filtered, loudness-normalized, resampled, and (for the movement
beds) crossfaded into seamless mono loops. The TNT recordings were shortened
and faded so chain reactions retain space between individual bursts.
