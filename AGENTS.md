# Agent Instructions

Follow Andrej Karpathy's four coding-agent rules:

1. Think Before Coding
   - Do not assume silently.
   - Surface ambiguity, assumptions, and tradeoffs before changing code.

2. Simplicity First
   - Write the minimum code needed to solve the requested problem.
   - Do not add speculative features, abstractions, or configurability.

3. Surgical Changes
   - Touch only the files and lines needed for the request.
   - Match the existing style.
   - Do not refactor unrelated code.

4. Goal-Driven Execution
   - Define what success means for the task.
   - Verify the result with the smallest relevant check.
   - Keep going until the requested goal is actually handled.
